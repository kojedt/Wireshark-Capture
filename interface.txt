Note: interface numbers shift as adapters are added/removed (e.g. Tailscale, vEthernet
were not present in earlier listings). Always re-run "tshark -D" (or capture_auto.py -D)
to confirm the current number before editing config.ini's "interface" key.

2. capture_auto.py settings (config.ini)
interface       = 8            # from the list above
duration        = 600          # seconds per capture file
retain_count    = 0            # keep last N files per day (0 = off)
retain_days     = 7            # raw .pcapng kept this many days, then zipped
retain_log_days = 30           # raw+zip deleted after this many days total
base_folder     = C:\captures
tshark_path     = C:\Program Files\Wireshark\tshark.exe

2b. capture_auto.ps1 settings (standalone, hardcoded, no retain_days/retain_log_days)
$tsharkPath   = "C:\Program Files\Wireshark\tshark.exe"
$outputFolder = "C:\Users\ARSIGCOMMgr\Desktop\captures"
$interface    = 8        # Change this to your interface number
$duration     = 5*60     # 5 minutes (in seconds)
$retainCount  = 10       # Keep only the last 10 captures

3. Build the exe (uses capture_auto.spec, output goes to dist\capture_auto.exe)
pyinstaller capture_auto.spec

After building, copy dist\capture_auto.exe and config.ini into cap\.
